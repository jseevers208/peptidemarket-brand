# PeptideMarket Brand · Signalis Bio

Fuente única de los activos de marca. **Este repositorio contiene el isotipo ORIGINAL de Signalis Bio** (S de dos aspas, esmeralda y plata, con columna de ocho puntos), vectorizado a partir del arte oficial del brochure el 3 de noviembre de 2026. Sustituye a todas las reinterpretaciones anteriores (v1 a v4).

## Archivos
- `signalis/original/signalis-mark.svg` · color (degradados esmeralda y plata). Clases: `blade-emerald`, `blade-silver`, `base-pairs`.
- Variantes derivadas (recolorear por clase, sin tocar la geometría): reverso = aspas esmeralda y puntos en #FFFFFF, aspa plateada en #C9CED3; monocromo = #1F2D29 y #9AA1A7.

ViewBox 654 x 1305 (vertical, proporción ~1:2). Tamaño mínimo: 10 mm / 32 px de alto. Espacio de respeto: la mitad del ancho del isotipo.

## Uso
- Sitio peptidemarket.co: `src/assets/signalis/` y `public/signalis/` se regeneran desde este SVG.
- Etiquetas de producto, empaques e imágenes generadas: usar siempre el PNG derivado de `signalis-mark.svg` como referencia.
- Nunca recolorear fuera de los tres modos, ni rotar, ni estirar, ni añadir efectos.
